\# QR code generator



QR code generator built with Python.





\## Features



* Generates QR code based on your input in 3 different formats
* Simple and easy to use 







\## Requirements 



* Python 3.x
* qrcode





\## Installation



Install the requirement library :



```bash



pip install qrcode



```



\## How to run



```bash



python main.py



```





Enter your text or URL to generate a QR code.
